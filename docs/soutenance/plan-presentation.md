# Plan de soutenance minuté — NINA-AES Platform

> Document vivant (v1). Cible : **30 minutes de présentation + ~10 minutes de questions**. Échéance
> de remise : **samedi 22 août 2026**. Jury **mixte** à servir simultanément : (1) professeur tuteur
> technique, (2) tuteurs CTDEC institutionnels, (3) jury académique UQAR généraliste. Ce plan
> complète `docs/soutenance/demo-script.md` (déroulé minute par minute de la démo) et
> `docs/soutenance/qa-anticipated.md` (questions anticipées). Le doc canonique de cadrage est
> `docs/26-RAPPORT-FINAL-SOUTENANCE.md`.

---

## 1. Principe directeur

La soutenance démontre **trois compétences** : maîtrise technique, vision systémique, communication
adaptée à un jury mixte. Trois leçons de cadrage guident ce plan :

1. **Démo live > slides.** Un jury voit en 30 secondes si un parcours fonctionne. La tranche démo
   (12-22) est le cœur du temps de parole.
2. **Honnêteté > esbroufe.** Le projet est un exercice académique mené par un étudiant seul. Chaque
   choix assumé (mock-first, backend non branché, governance MVP, FR+BM) est présenté comme une
   **décision de conception justifiée**, pas comme une lacune cachée.
3. **Parler aux trois jurys à la fois.** Chaque tranche identifie son audience prioritaire mais ne
   perd jamais les deux autres.

### Tranche 6-12 — Architecture technique (microservices, stack, sécurité)

| Champ            | Contenu                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Durée            | 6 min                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Contenu          | Vue d'ensemble : monorepo **Turborepo/pnpm**, 3 apps front **Next.js (App Router)** (citizen, admin, governance), une constellation de **15 répertoires de services** backend (11 cœur + api-gateway + 3 différés) et **14 packages partagés**. Insister sur **3 idées d'architecture fortes** : (a) la **« couture » de données** via `@nina-aes/api-client` — interface unique, deux implémentations interchangeables (mock / API réelle) ; (b) la **sécurité by design** ; (c) la **souveraineté**. Détailler 4 points forts sécurité : QR sécurisé en **JWT RS256** (corrige la faille du QR contenant le NINA en clair), journal d'audit **immuable chaîné Merkle** (append-only, trigger PostgreSQL), interop AES en **mTLS + JWS Ed25519** (aucune donnée personnelle transmise : un booléen + un score), secrets via **HashiCorp Vault**, mots de passe **Argon2id**, MFA, RBAC 6 rôles. |

## 3. Règle d'or — parler à trois jurys à la fois

À chaque affirmation, vérifier qu'elle **atterrit pour les trois audiences** :

- **Pour le tuteur technique** : _comment_ c'est fait (couture api-client, JWT RS256, Merkle,
  mTLS/JWS Ed25519, Vault, Argon2id, monorepo). Précision et trade-offs assumés.
- **Pour les tuteurs CTDEC** : _quel problème terrain_ c'est résolu (erreurs d'état civil corrigées,
  anti-corruption SIGAC, souveraineté des données, accès des vulnérables via USSD/8 langues). Aucune
  PII ne sort des frontières.
- **Pour le jury académique généraliste** : _pourquoi ça compte humainement_ et _quelle rigueur de
  méthode_ (problème → vision → réalisations → limites assumées → perspectives).

Méthode pratique : après chaque point technique, **une phrase « pourquoi ça compte »** orientée
droits humains / institution. Et inversement, après chaque point humain, **un ancrage concret** dans
l'implémentation. C'est l'alternance qui tient les trois jurys ensemble.

Trois réflexes transverses :

1. **Annoncer avant de montrer** (surtout le mock, surtout les limites) : annoncer un choix le
   transforme en décision ; le laisser découvrir le transforme en faute.
2. **Distinguer le fait du plan** : ce qui tourne aujourd'hui vs. ce qui est conçu/planifié. Jamais
   d'ambiguïté, jamais de chiffre inventé.
3. **Rester dans le temps** : la démo est protégée par une montre. Un dépassement ampute toujours la
   conclusion, qui est la partie la plus valorisante (limites assumées + perspectives).
